# Editor de Escriturações para o SPED

Objetivos iniciais do projeto:

- Permitir a importação, edição e exportação de escriturações, mantendo a validade da estrutura.
- Permitir a criação de escriturações do zero, embora não seja o foco principal.
- Realizar validações de estrutura, mas não conteúdo.
- Suportar pelo menos a EFD ICMS/IPI e a EFD PIS/COFINS.

## Escriturações SPED Planejadas

- [x] EFD ICMS/IPI
- [x] EFD PIS/COFINS
- [ ] ECD
- [ ] ECF
